# Emotion Detector

## 📌 Project Description
This project is an Emotion Detection web application that analyzes user input text and identifies emotions such as joy, anger, sadness, fear, and disgust using IBM Watson NLP.

## 🚀 Features
- Detects emotions from text input
- Displays dominant emotion
- Uses IBM Watson AI model
- Includes fallback logic for reliability
- Unit testing implemented

## 🛠️ Technologies Used
- Python
- Flask
- IBM Watson NLP API
- Requests Library

## 📂 Project Structure
- EmotionDetection/ → Core emotion detection logic
- server.py → Flask web application
- test_emotion_detection.py → Unit tests
- README.md → Project documentation

## ▶️ How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the server:
   python server.py

3. Open browser and test
